# زادِي — العلوم الإسلامية للبكالوريا

مراجعة تفاعلية لمادة العلوم الإسلامية (بكالوريا الجزائر): خرائط ذهنية، بطاقات حفظ،
تحدّي ملء الفراغات، اختبارات QCM، بنك أسئلة بكالوريا، ومراجعة سريعة — تعمل دون إنترنت.

## بنية المستودع

```
.
├── web/                # تطبيق Next.js 16 (اقرأ web/README.md أولًا)
├── lessons/            # صور الخرائط الذهنية المصدرية (PNG عالي الدقة)
├── resources/          # المراجع الأصلية: PDF/DOCX (≈116MB) — انظر resources/README.md
├── REVIEW.md           # مراجعة شاملة للمحتوى/الجودة/البيانات (بالعربية)
├── UX_REVIEW.md        # مراجعة تجربة المستخدم والواجهة (بالعربية)
└── .github/workflows/  # CI: typecheck + lint + اختبارات بيانات + build + smoke
```

بيانات الدروس نفسها في `web/src/data/lessons/` — **هي المصدر الوحيد** (لا نسخ موازية).

## البدء السريع

```bash
cd web
pnpm install
pnpm dev        # http://localhost:3000
```

```bash
pnpm verify     # typecheck + lint + اختبارات سلامة البيانات
pnpm build
```

## مراجعات موثّقة

- **[REVIEW.md](REVIEW.md)** — مراجعة المحتوى والأخطاء الوظيفية والأداء وSEO، مع قسم
  «ما تم إصلاحه فعليًا».
- **[UX_REVIEW.md](UX_REVIEW.md)** — مراجعة تجربة المستخدم: رحلة الطالب، تكدّس
  المعلومات والأزرار، الحمل الإدراكي، وإصلاح الوضع الفاتح.

## المساهمة

1. أي تعديل على `src/data/lessons/*.json` يجب أن يمرّ بـ `pnpm verify`.
2. أي وحدة جديدة: اتبع القسم «إضافة وحدة جديدة» في `web/README.md`.
3. المحتوى التعليمي يُراجَع بشريًا قبل النشر (خصوصًا ضبط الشواهد برواية ورش).
