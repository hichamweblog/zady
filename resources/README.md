# المواد المصدرية

هذا المجلد يحتوي **116MB** من المراجع الأصلية التي بُني منها محتوى التطبيق:
ملخصات الدروس، أسئلة الفهم، أسئلة البكالوريا الرسمية (2020–2025)، ومنهجية الإجابة.

> ⚠️ **ملاحظة على الحجم:** وجود هذه الملفات داخل Git يضخّم المستودع (`.git` ≈ 107MB)
> ويبطئ كل استنساخ. المستحسن مستقبلًا نقلها إلى تخزين خارجي (Drive / S3 / R2)
> وإبقاء فهرس الروابط هنا. أُضيف ملف `.gitattributes` في الجذر بحيث تُخزّن ملفات
> PDF/DOCX/PNG الجديدة عبر **Git LFS** تلقائيًا.
